# Isolated Request Completion Email

This directory preserves the disabled completion-email implementation for a future, separately approved delivery.

Nothing here is loaded by the frontend, Supabase migrations, or Edge Function deployment. Do not rename these files into executable locations until the Resend account exists, estudeipe.com.br is verified, Supabase secrets and Vault values are configured, the SQL is reviewed against the then-current schema, and a real delivery is approved.

Reactivation requires independent authorization for the database migration, Edge Function deployment, secrets, production publication, and the live email test.
